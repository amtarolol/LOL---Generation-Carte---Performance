# Space Invaders++

**Un jeu de type shoot'em up inspiré de Space Invaders, optimisé pour explorer les défis de performance avec Pygame.**

![Space Invaders++ Screenshot](assets/images/screenshot.png) *(Exemple d'image à ajouter)*

---

## 📖 Description
Space Invaders++ est une version avancée du classique Space Invaders, conçue pour tester et optimiser les performances avec Pygame. Le jeu met l'accent sur :
- **Un grand nombre d'ennemis et de projectiles** à l'écran.
- **Des effets visuels** (explosions, particules, animations).
- **Des collisions complexes** entre objets.
- **Des vagues d'ennemis** de plus en plus denses.

L'objectif est d'explorer différentes techniques d'optimisation pour maintenir un jeu fluide, même avec des centaines d'objets à gérer.

---

## 🛠 Prérequis
- **Python 3.8+** (recommandé : Python 3.10 ou supérieur)
- **Pygame 2.0+** (installé via pip)
- **SDL2** (généralement installé automatiquement avec Pygame)
